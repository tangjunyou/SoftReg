# Phase 2 · 官网提交教练（人工断点引导）

本阶段的目标：把已生成且体检通过的申请材料，引导用户在中国版权保护中心官网完成在线提交。
本阶段**不做任何绕过**：登录、实名、短信授权码、签字盖章必须由用户本人完成；agent 的角色是教练 + 对照员 + 体检员。

官方入口（认准官网，谨防代办山寨站）：

- 中国版权保护中心：<https://www.ccopyright.com.cn/>
- 著作权登记系统（登录/注册）：<https://register.ccopyright.com.cn/login.html>
- R11 计算机软件著作权登记直通：<https://register.ccopyright.com.cn/r11.html>

## 0. 提交前检查清单（agent 逐项核对，全部通过才进入下一步）

1. `正式资料/代码鉴别材料.pdf` 已通过 `pdf_check.py`（PASS，页数=60 或全部模式实际页数）。
2. `正式资料/操作手册.pdf`（或 docx 导出的 PDF）已通过 `pdf_check.py`（文档密度按每页 ≥30 行）。
3. 申请表信息 txt 中：软件全称、版本号与两份 PDF 页眉完全一致（逐字符比对，有无 V 以申请表为准）。
4. 著作权人证件材料已备好：个人=身份证正反面照片（清晰、平铺、无反光）；法人=营业执照副本扫描件。
5. 开发方式若为合作/委托/任务开发：对应合同或任务书扫描件已备好。
6. 用户已完成官网注册 + **实名认证**（实名审核可能需要约 3 天，必须提前完成；未实名则先引导用户去完成，今天到此为止）。

## 1. 在线填报（R11，六步向导，2026-09 官网实证）

实际步骤：①选择办理身份 → ②软件申请信息 → ③软件开发信息 → ④软件功能与特点（**鉴别材料上传在这一步页内下半部**）→ ⑤确认信息 → ⑥填报完成。

引导路径：官网登录 → 业务办理 → 选择「R11 计算机软件著作权登记」。

关键选择（逐项和用户确认后再继续）：

1. **我是申请人 / 我是代理人**：
   - 著作权人是用户本人 → 选「我是申请人」。
   - 著作权人是学校/单位（评奖评优要求著作权人为单位）→ 选「我是代理人」，后续授权码发到**单位绑定手机号**（每天限量约 3 条，需提前与单位经办人预约；验证码 1 小时有效）。
   - 用户没有明确的单位要求时，建议个人申请：流程最短、责任最清。
2. **软件分类**、**开发完成日期**、**发表状态**（建议「未发表」，可少填内容）、**著作权人**信息：从 `申请表信息.txt` 逐字段对照填入。
3. 字符硬约束（超限官网会拒绝提交）：
   - 各硬件/系统/环境字段 ≤50 字符
   - 软件的主要功能 **500~1300 字符**（先在本地数字符，粘贴前核对）
   - 技术特点描述 ≤100 字符
   - 源程序量：纯数字，不带"行"
4. 若 agent 具备浏览器能力（如 Chrome DevTools / browser 工具）：可打开官网页面协助**只读核对**；用户亲手登录、亲手填写敏感字段（证件号等）。不具备浏览器能力时，把字段对照表打印在对话里，让用户逐项填写后回报，agent 负责复核口径。

## 2. 上传鉴别材料（位于第④步"软件功能与特点"页内）

官网实证（2026-09）：程序鉴别材料、文档鉴别材料各为**单文件上传槽**（multiple=false，提示"请上传pdf格式"），另有"其他相关证明文件"槽。
1. 程序鉴别材料：选「一般交存」，上传**单个** `代码鉴别材料.pdf`（前30+后30 已合并为一个文件——这正是单 PDF 设计的原因）。
2. 文档鉴别材料：选「一般交存」，上传 `操作手册.pdf`。
3. 其他相关证明文件：有则上传，无则跳过。
4. 第⑤步确认信息页会列出「提交材料清单」：打印签字或盖章的登记申请表、著作权人身份证明复印件、鉴别材料页数；页面提供「保存至草稿箱」，**「确认填报」触发正式提交与授权码流程，点之前必须完成全部人工确认**。**页数与份数需按官网要求手写在提交材料清单上：与 `代码鉴别材料.manifest.json` 的实际页数（前30+后30=60 或全部提交模式的实际页数）和申请表「页数」字段逐一核对一致后再寄出。**

## 3. 短信授权码（人工断点，必须提醒）

- 提交前需要授权码：个人=本人手机号；单位=绑定经办人手机号。
- 授权码 **1 小时有效**；获取后**不要刷新页面、不要关闭浏览器、不要断网**，否则整个在线填报流程作废重来。
- agent 此时应暂停一切操作，明确告知用户："验证码已发送，请在官网页面输入，完成后告诉我。"

## 4. 申请确认签章页（人工断点）

1. 在线填报完成后，官网生成申请确认签章页，**下载打印**（不得更改内容、格式和打印比例）。
2. 个人申请：本人签名（+按官网当期要求填写身份证号）。
3. 单位申请：加盖单位公章（鲜章），按单位内部流程走审批。
4. **注意**：签章页条款在动态变化——若当期签章页含「未使用 AI 生成申请材料」「征信承诺」等条款，需按页面要求**手抄承诺内容**并签名。以用户当次实际下载的签章页为准，agent 不得替用户判断跳过。
5. 签章后扫描为 PDF（清晰、无反光、无遮挡），上传官网并提交。

## 5. 提交后告知用户

- 官网用户中心 → 消息中心会以站内信通知受理与补正；也可定期登录「我的登记-软件登记」查看流水号状态。
- 法定时限：受理日起 60 日内审查完成；加上填报与单位流程，全程常见 4~5 个月。
- 补正期只有 **30 日**，逾期视为撤回——提醒用户每周至少查看一次消息中心。
- 证书为电子证书（PDF），在用户中心下载，可本地/在线验签。
