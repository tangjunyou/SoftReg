# Phase 3 · 进度管家（提交后跟踪与补正应对）

## 1. 状态跟踪

查询路径：register.ccopyright.com.cn 登录 → 用户中心 → 我的登记 → 软件登记 → 按流水号查看详情。

正常流转：提交 → 受理 → 审查（法定 60 日内完成）→ 登记办结 → 电子证书可下载。
全程常见 4~5 个月（含单位内部流程）。

agent 做的事：

- 每次会话中用户问进度时，引导其登录查看；有浏览器能力时可代为打开查询页（只读）。
- 提醒节律：提交后第 1 周确认「已受理」；此后每 2~4 周看一次消息中心站内信。

## 2. 收到补正通知（30 日内必须处理，逾期视为撤回）

补正通知在 用户中心 → 消息中心 站内信。收到后：

1. 让用户把补正意见原文贴出来（或截图）。
2. 按意见类型路由回对应阶段重新生成材料：

| 补正意见常见措辞 | 根因 | 回到哪个阶段 |
|---|---|---|
| 页数/行数/页眉/格式不符合要求 | 排版问题 | Phase 1 重跑 build_code_pdf + pdf_check |
| 鉴别材料含模板化、雷同、疑似 AIGC 内容 | 文档 AI 味 | Phase 1 手册重写：人工深度改写 + 增加真实项目细节 |
| 文档与程序鉴别材料内容不符 | 手册写了代码没有的功能 | Phase 1 业务理解重审，手册按真实代码功能收敛 |
| 源程序为通用框架程序 | 代码无业务逻辑 | Phase 0 补充业务代码后再走 Phase 1 |
| 权属证明/身份证明问题 | 证件材料问题 | 按意见补扫描件，不涉及本 skill |
| 签章页问题（未手抄承诺/比例改动） | 签章问题 | 重新打印签章页，按当期要求手写+签章 |

3. 重新生成的材料必须与已提交部分保持口径一致（软件全称、版本号、日期不动）。
4. 上传补正材料后，再次提醒用户确认站内信状态更新。

## 3. 下证后

- 电子证书 PDF 在用户中心下载；右下角有电子签章，WPS 等可本地验签。
- 建议用户归档：证书 + 提交材料副本 + `代码鉴别材料.pdf.manifest.json`（材料追溯清单）。
- 若同一软件后续升级再登记（V2.0），走「修改」口径并填写原登记号。
